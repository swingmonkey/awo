# 《全天候运行规定》互动学习网页

## 项目简介

本项目是一个基于《全天候运行规定》(AC-91-FS/CA/TM-2026-16R2)的互动学习网页，旨在帮助航空公司运行人员和民航从业人员更直观地理解和掌握全天候运行的相关规定和标准。

## 功能特点

- **核心对话**：通过航空公司运行副总经理(AOC Chief)与民航局飞行标准监察员(Inspector)之间的对话，生动解释全天候运行规定的核心内容
- **音频讲解**：提供音频讲解功能，用户可以边听边学
- **官方文档链接**：直接链接到民航局官方发布的《全天候运行规定》文档
- **响应式设计**：适配不同屏幕尺寸，在桌面端和移动端都能良好显示
- **悬浮窗口**：音频播放器和官方文档链接采用悬浮窗口设计，方便用户随时访问

## 如何使用

1. 打开 `index.html` 文件即可访问学习网页
2. 点击右侧悬浮窗口中的音频播放器收听讲解
3. 点击官方文档链接查看完整的《全天候运行规定》
4. 阅读核心对话部分，了解全天候运行的关键概念和标准

- 本网页为学习用途，实际运行请严格遵守民航局最新规定
- 音频文件 `bc001_min.mp3` 需要与 `index.html` 放在同一目录下
- 网页中的官方文档链接指向民航局发布的《全天候运行规定》(2026年版)
